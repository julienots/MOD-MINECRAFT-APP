# Exemples

`Exemple_Sanglier_des_mousses_v1.0.0.mcaddon` : addon généré par l'application (projet d'exemple).

Contenu (tout est original) :
- une créature neutre `exemple_bms:sanglier_mousses` : comportement, modèle quadrupède, texture, animations, butin, apparition naturelle, œuf d'apparition ;
- un objet `exemple_bms:croc` ;
- une épée `exemple_bms:epee_croc`, réparable avec le croc, et sa recette d'établi (2 crocs + 1 bâton) ;
- un bloc de minerai `exemple_bms:pierre_moussue` qui laisse 1 à 2 crocs ;
- une recette au four : os → croc ;
- les noms en français et en anglais.

Il passe la vérification de l'application sans erreur. **Il n'a pas encore été testé dans Minecraft** : c'est le premier essai à faire sur ton téléphone (ouvre le fichier avec Minecraft, active les deux packs dans un monde, puis `/summon exemple_bms:sanglier_mousses`, `/give @s exemple_bms:epee_croc`, `/give @s exemple_bms:pierre_moussue`).

Le même projet se crée dans l'application avec « Ouvrir le projet d'exemple ».
