# Exemples

`Exemple_Sanglier_des_mousses_v1.0.0.mcaddon` : addon généré par l'application (projet d'exemple).

Contenu : une créature neutre originale (`exemple_bms:sanglier_mousses`) avec comportement, modèle quadrupède, texture, animations de marche et de regard, butin (côtelettes de porc), apparition naturelle à la surface de l'Overworld, œuf d'apparition et noms en français et en anglais.

Il passe la vérification de l'application sans erreur. **Il n'a pas encore été testé dans Minecraft** : c'est le premier essai à faire sur ton téléphone (ouvre le fichier avec Minecraft, active les deux packs dans un monde, puis `/summon exemple_bms:sanglier_mousses`).

Le même projet se crée dans l'application avec « Ouvrir le projet d'exemple ».
